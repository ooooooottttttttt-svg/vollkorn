# Vollkorn

Одностраничный сайт о шрифте Vollkorn. Название шрифта с немецкого переводится как «цельнозерновой», поэтому я рассказываю о нём через образ пекарни и хлеба.

## Что я научилась делать

- Располагать картинки и текст внутри секции через `position: relative` у секции и `position: absolute` у элементов
- Обрезать картинки, которые выходят за край секции, с помощью `overflow: hidden`
- Подключать шрифт с Google Fonts и показывать все 12 начертаний, от Regular до Black Italic
- Пускать текст по кругу через SVG и `textPath`. Это было самое трудное: долго подбирала длину текста, чтобы надпись замыкалась на тарелке
- Убирать висячие предлоги и союзы неразрывным пробелом `&nbsp;`
