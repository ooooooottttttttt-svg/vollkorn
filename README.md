### Записи о запросах

#### Запись №1 · 25.10.2026

- **Что я хотела сделать:** загрузить сайт на GitHub и получить ссылку, по которой сайт открывается сразу, в любом браузере.
- **Что я спросила:** «Как загрузить файлы в GitHub? У меня папки images и styles не загружаются, могу только отдельные файлы из папок».
- **Что ответил ИИ:** объяснил, что можно создать папку прямо на GitHub: в Add file → Create new file набрать `images/keep.txt`, а потом зайти в папку и загрузить в неё файлы. Ещё объяснил, что `github.com/логин/vollkorn` — это ссылка на репозиторий, а сам сайт открывается по ссылке `логин.github.io/vollkorn`, после того как включишь Pages.
- **Что я изменила сама:** сама создала папки `images` и `styles`, загрузила в них файлы, а `index.html` положила в корень репозитория. Включила Pages в Settings → Pages (ветка main, папка / (root)).
- **Как я поняла, что это работает:** в репозитории появились папки `images`, `styles` и файл `index.html`, а по ссылке github.io открылся мой сайт с картинками и шрифтом.

#### Запись №2 · 24.10.2026
